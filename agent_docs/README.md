# Agent Docs Index

This folder contains **low-token, high-signal** documentation for AI agents.
Only open files here when you need deeper context than `AGENTS.md` and `CLAUDE.md`.

Docs:

- `EXPLORATION_GUIDE.md` – How to explore the NestJS monolith and find the right modules.
- `NEST_BACKEND_OVERVIEW.md` – Architecture, modules and cross-cutting concerns.
- `FEATURE_WORKFLOW.md` – Step-by-step workflow to implement a new feature (entity → repo → service → controller → DTOs → tests).
- `USERS_MODULE_GUIDE.md` – Canonical example module; use it as a template for new features.
- `TESTING_GUIDE.md` – Testing strategy, tools and expectations.
